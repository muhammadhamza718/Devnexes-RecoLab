# API Reference: Recommendation Models (`src/recolab/`)

## 1. `PopularityModel` (`src/recolab/baseline.py`)
Non-personalized baseline model ranking items by interaction count or mean rating.

```python
class PopularityModel(Recommender):
    def __init__(self, metric: str = "count"): ...
    def fit(self, ratings_df: pd.DataFrame, movies_df: Optional[pd.DataFrame] = None) -> "PopularityModel": ...
    def recommend(self, user_id: int, k: int = 10, exclude_items: Optional[List[int]] = None) -> List[Tuple[int, float]]: ...
    def to_bundle(self) -> ModelBundle: ...
    @classmethod
    def from_bundle(cls, bundle: ModelBundle) -> "PopularityModel": ...
```
